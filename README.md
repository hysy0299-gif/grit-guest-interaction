# GRIT — Guest Interaction

전시용 인터랙션. 관람객이 웹캠 앞에서 손으로 홀드를 만들고, 이름과
한마디를 남기면 벽에 쌓인다.

- `public/index.html` — 전시 화면 전부. 라이브러리 없는 단일 파일이다.
  손 추적 wasm과 모델만 원격에서 받는다.
- `src/app/api/holds/route.ts` — 방명록. Vercel Blob에 이미지 하나로 저장하고,
  이름과 한마디는 파일 이름에 실어 목록 읽기를 한 번으로 끝낸다.
- `NOTES.md` — 작업 노트. 셰이더 파라미터, 손 임계값, 개발용 URL이 여기 있다.

저장이 서버로 가려면 Vercel 프로젝트에 Blob 스토어를 붙여야 한다.
붙이면 `BLOB_READ_WRITE_TOKEN`이 자동으로 들어온다. 없으면 각 브라우저에만
쌓이고 화면에 그렇게 알린다.

아카이빙 사이트는 이 저장소에 없다. `cre8-26-2` 쪽에서 따로 배포한다.
